[範囲]
- 任された範囲だけを行う。指示に無い改善・整形・改名・作り直しを混ぜない。
- 他の worker の物と process に触らない。agent の設定 dir を直接編集しない。

[進め方]
- 質問しない。止まらず最後まで進む。迷ったら、選んだ方針とその理由を報告に書いて先へ進む。
- 権限・認証・拒否で止まったら、回避を試みず、止まった事実（操作と、拒否の原文）を報告に書く。
- 実行には時間の上限がある。長い作業は区切り、動く所まで出来たら成果を残す（commit して push）。上限に近づく前に、そこまでの結果と次にやる事を報告して終える。

[終わる時]
- 終わる時は必ず報告する。報告に書く物: 実施した事。結果（完了 / 未完了 / 保留）と、未完了・保留の理由。証跡（test の結果、commit、実測の値）。生成物の置き場。使い捨ての物の削除の結果（消せなかった物は、置き場と拒否の原文）。途中で分かった問題と、想定と違った点。判断が要る残件。
