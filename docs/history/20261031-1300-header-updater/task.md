# 指示書: アップデートの確認と「更新して再起動」をヘッダーに置く（cmux 方式）

- 日付: 2026-10-31 / 発行: Mac main cap
- 実行: 204 remote cap。worker は sonnet か opus（Fable は使わない）。cargo は `CARGO_BUILD_JOBS=2`・`-j 2`、コマンドは逐次。
- 作業 dir: `/home/vagrant/work/bantou/develop`（branch develop）。

## ユーザー指示

- 更新ありの時の再起動ボタンを GUI のヘッダーに入れる。アップデート確認のボタンもヘッダーに入れる。
- 参考は cmux: サイドメニュー下部に「アップデートを確認」ボタンがあり、アップデートがあると同じ場所に「アップデートして再起動」ボタンが出る。同じような仕様にする。

## 仕様

- ヘッダーの 1 か所（フォルダ未選択でも出る位置）に更新の操作を置く。状態で表示が替わる:
  - 通常: 「アップデートを確認」。押すと確認中の表示 → 最新なら「最新」と短く出して通常に戻る。失敗なら理由を出す。
  - 更新あり: 同じ場所が「アップデートして再起動（v<版>）」に替わる。押すとダウンロード（進捗表示）→ 再起動。
  - 起動時の自動チェックで更新が見つかった時も、この場所が「更新あり」になるだけ。
- 今のトースト通知（UpdaterToast）は廃止し、この 1 か所に集約する。アプリメニューの「アップデートを確認...」は残し、同じ状態を動かす。
- 既存の updater の状態機械（useUpdater）は流用してよい。

## テスト

- e2e mock と spec を合わせる（通常 → 確認 → 最新、更新あり → ヘッダーのボタン → download・restart が呼ばれる、フォルダ未選択でも出る）。既存の updater.spec はこの仕様に置き換え。
